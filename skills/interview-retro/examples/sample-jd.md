# 后端开发工程师（交易平台方向）— 某互联网公司 JD（脱敏样例）

## 岗位职责
1. 负责交易平台核心链路的服务设计与开发，保障高并发场景下的稳定性与性能。
2. 参与订单、库存、支付等核心系统的架构演进，推动服务拆分与技术选型。
3. 负责线上问题的定位与复盘，建设监控告警与容量规划体系。
4. 推动跨团队协作，与产品、风控、客服团队共同交付业务需求。

## 任职要求
1. 本科及以上学历，3 年以上后端开发经验，熟悉 Java 或 Go。
2. 熟悉 MySQL、Redis、Kafka 等常用中间件，理解其原理与适用边界。
3. 具备高并发系统的设计与性能调优经验，熟悉压测与容量评估方法。
4. 熟悉分布式事务与数据一致性方案，了解限流、熔断、降级等稳定性手段。
5. 有良好的问题排查能力，能独立完成线上故障定位与根因分析。

## 加分项
- 有交易类系统经验，理解资金安全与幂等设计。
- 有成本优化经验，能在保证稳定性的前提下降低资源占用。
- 有 Kubernetes 与云原生相关实践经验。
